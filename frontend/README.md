Pizza Palace

A full-stack MERN Pizza Ordering Application built using React, Node.js, Express.js, and MongoDB. The application allows users to register, log in, browse pizzas, add items to the cart, place orders, and view their order history.

🚀 Features

User Features

- User Registration
- User Login & Logout
- Browse Available Pizzas
- Add Pizzas to Cart
- Increase/Decrease Quantity
- Place Orders
- View Order History
- Responsive User Interface

Admin Features

- Add New Pizzas
- Store Pizza Details in MongoDB
- Manage Pizza Menu Dynamically

🛠️ Technologies Used

Frontend

- React.js
- React Router DOM
- Axios
- React Toastify
- CSS

Backend

- Node.js
- Express.js
- JWT Authentication
- bcryptjs

Database

- MongoDB Atlas
